GPUVideo Help

GPUVideo allows you to play video files using a GPU peripheral in ComputerCraft. It requires the video files to be hosted on a local server.

Video Server Setup

This setup is optimized for a web server running through IIS on Windows:

  1. Open the Windows search bar and search for "Turn Windows features on or off".
  2. Enable Internet Information Services (IIS) and install it.
  3. Search for "IIS" and open Internet Information Services (IIS) Manager.
  4. Right-click your computer name on the left and select Add Website.
  5. Set the Physical Path to the folder where you will store the video frames (this may use a lot of space).
  6. Set the Port to 491, choose a name, and leave all other fields as default. Click OK.
  7. Open the folder you set in the path. Use Online Converter to convert your video to JPG frames. Upload your MP4, convert it, download the zip, and extract it to the folder.
  8. Edit video.lua and set frame to the lowest number and maxFrame to the highest number in the folder.

Audio Setup

  1. Convert your MP4 to an MP3 using CloudConvert.
  2. Use Music Converter to convert the MP3 to audio.dfpwm.
  3. Locate your ComputerCraft folder: go to your singleplayer world list, click Edit on your world, then Open Folder. Open the computercraft/computers/ID folder corresponding to your computer and place audio.dfpwm there.

Installation

wget run https://mg.madefor.cc/GPUVideo/Installer.lua

Usage

Ensure you have both a GPU and a Speaker peripheral connected. Run play.lua to start the video.
